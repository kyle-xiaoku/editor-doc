功能特性

公众号排版要用的，基本都在里面

从版心、字号到上传、源码、Markdown，全部内置；也可以按需裁剪，只要核心体积不到 200 KB。

公众号版式

默认 677px 正文版心、17px / 1.75 行距，窄屏自动收窄。宽屏采用 fluid 版心随容器生长，两侧留白恒定为 paperGap，不会留出一大块空白。

paperWidth · paperMode · paperGap

上传：整包 + 分片

普通上传与分片上传各自独立配置。分片只打一个接口，响应里 url 非空即成功，天然支持秒传；并发、重试、取消、断点续传都在。

uploader · chunkUploader · upload.mode

代码块 + 语法高亮

20 种语言可选，支持按别名搜索（js / mysql / yml）。光标落在块内可边写边高亮；产物是干净代码，重新导入会自动重新着色。

insertCode · setCodeLanguage · 零依赖高亮器

Markdown 一键导入

选文件、拖文件或直接粘文本，实时预览转换结果与结构统计，再选落点（替换全文 / 追加文末 / 插入光标）。把 .md 拖进正文也能转。

importMarkdown · markdownToHtml

HTML 源码模式

工具栏常驻「源码」按钮，⌘/Ctrl+Shift+K 直达。格式化缩进、一键复制、直接编辑并应用（回填自动净化），方便对接第三方模板。

enterSource · getHTML({clean:false})

图片编辑在手边

点击图片浮出气泡工具条（对齐 / 宽度 / 圆角 / 替换 / 删除），右下角拖拽把手可按百分比实时缩放，双击看原图，大图上传前自动压缩。

自定义工具栏按钮

用 customButtons 加下拉选择按钮：数据可静态配置或从接口读取，选中后插入跳转链接或直接打开。面板自带搜索、分组、加载与重试。

position 可放到工具栏任意位置

安全与零依赖

标签 / 属性双白名单净化，拦截 on*、javascript:、script/iframe。纯前端运行，样式随 JS 注入，不用额外引 CSS，也不上传任何内容到远端。

sanitizeHtml · 内置高亮器与 MD 转换器

高度自适应

不配 height 时内容区随内容撑开、整页滚动，工具栏尽量吸附视口顶部；配上就固定高度并内部滚动。实时字数 / 图片 / 视频统计开箱可用。

setHeight(0) 回到自适应
接入方式

三行代码，接进你的项目

支持 <script> 直接引入、ESM / 打包器，以及作为 Vue 3 组件安装。三种方式 API 完全一致。

零构建，直接可用 
<div id="editor"></div>
<script src="https://unpkg.com/kyle-editor"></script>
<script>
  const editor = KEditor.create('#editor', {
    placeholder: '开始撰写内容，支持拖拽 / 粘贴图片与视频…',
    primaryColor: '#07c160',
    // 高度默认随内容自动撑开；要固定高度 + 内部滚动就写 height: 460

  editor.on('change', ({ html }) => console.log(html))
</script>

unpkg / jsdelivr 的默认入口就是压缩版，因此 unpkg.com/kyle-editor 与 .../dist/keditor.umd.min.js 等价。调试可换成未压缩的 keditor.umd.js，全局变量与 API 完全一致。

组件用法 
<template>
  <k-editor v-model="form.content" :options="options" :disabled="saving" @upload="onUpload" />
</template>

<script setup>
import { ref } from 'vue'

const form = ref({ content: '' })
const options = {
  height: 420,                          // 不写 = 自适应内容高度
  uploader: '/api/upload',              // 普通上传：整个文件一次请求
  chunkUploader: '/api/chunk-upload',   // 分片上传：大文件自动切片（≥ 5MB）

}

</script>

kyle-editor/vue 的默认导出就是组件本身（自带 install），所以 app.use() 与直接当组件用两种写法等价；只想显式拿插件时用 import { KEditorPlugin }。

上传

整包与分片，两条链路各自独立配置

小图走普通上传（整个文件一次请求），大视频走分片上传（切片并发 + 重试）。 两条链路互不影响，可以只配一条，也可以都配；配了一条就不会被默认的 mock 静默顶上， 避免真实后端只接了一半却产生 blob: 假地址。

  • 分片只需一个接口：每片都 POST 到 chunkUploader，某个响应里 url 非空即代表整个文件成功，剩余分片不再上传 —— 天然支持秒传。
  • 自动选路：upload.mode 默认 'auto'，达到 chunkThreshold（默认 5MB）才走分片。
  • 进度、速度、取消、重试齐备，占位块失败会转错误态并提供「重试 / 移除」，不会静默当成功。
  • 没后端也能跑：默认 'mock' 适配器生成 blob: 地址，改一行配置即接真实接口。
查看上传接入细节
两条链路，各配各的 
KEditor.create('#editor', {
  uploader: '/api/upload',            // 普通上传（整包）
  chunkUploader: '/api/chunk-upload', // 分片上传（切片并发）

  upload: {
    mode: 'auto',                     // auto | normal | chunk
    chunkThreshold: 5 * 1024 * 1024,  // 达到该体积才分片
    chunkSize: 1024 * 1024,           // 分片大小
    concurrency: 4,                   // 并发分片数
    retries: 2,                       // 单片失败重试
  },
})

// 需要鉴权 / 自定义字段时（两条链路写法相同）
chunkUploader: {
  type: 'http',
  url: '/api/chunk-upload',
  fieldName: 'chunk',                                   // 默认 'file'
  headers: () => ({ Authorization: `Bearer ${getToken()}` }),
  parse: (json) => json.data,                           // 默认 json.data ?? json
  pickUrl: (json) => json?.payload?.filePath || '',     // 默认认 url / fileUrl / src
}
Markdown

把 .md 文件直接变成可编辑的公众号正文

尾栏「导入MD」按钮打开导入面板：选文件 / 拖文件 / 粘文本，实时预览转换结果与结构统计， 再选落点导入。把 .md、.markdown、.txt 文件拖进正文也能直接转换。

  • 三种落点：替换全文（默认）/ 追加文末 / 插入光标，面板里随时切换。
  • GFM 子集：标题、嵌套/松散/任务列表、表格（列对齐写进 style）、引用、围栅代码块、行内语法、引用式与自动链接、图片。
  • 代码块语言保留并高亮：围栅语言经归一后写成 data-k-lang + class="language-x"，直接接入高亮。
  • 产物再过一遍白名单净化，<script>、on*、javascript: 会被清掉或转义；编码自动兜底 GBK / GB18030 / Big5。

导入与落点 
KEditor.create('#editor', {
  markdown: {
    insertMode: 'replace',      // replace | append | cursor
    maxSize: 5 * 1024 * 1024,   // 单文件上限，0 = 不限
    gfm: true,                  // 表格 / 删除线 / 任务列表 / 裸链接
    breaks: false,              // 段落内单换行是否转 <br>
    linkTarget: false,          // 外链自动加 target + rel
    frontMatter: true,          // 丢弃开头 YAML front matter
  },
})

// source 支持 文本 / File / { name, content }
await editor.importMarkdown(mdText)
await editor.importMarkdown(file, { mode: 'append' })
await editor.setMarkdown(mdText)    // 替换全文
await editor.appendMarkdown(mdText) // 追加文末

editor.on('markdownimport', ({ mode, name, summary }) => {
  console.log(mode, name, summary)
})

代码块

20 种语言，边写边高亮

点工具栏「代码块」就是语言面板，支持按名称或别名搜索。光标已经在某个代码块里时， 同一个面板变成「代码块语言」，选一项即改写当前块并重新着色。

高亮器是内置的极简 tokenizer（零依赖），正则带长度保护：单块超过 60 KB 按纯文本处理，避免长文卡顿。

plaintext javascript typescript html css json python java go rust c csharp php ruby sql bash yaml ini markdown diff

别名同样可用：js ts py golang yml mysql c++ md

语言与高亮 API 
KEditor.create('#editor', {
  code: {
    languages: ['js', 'python', 'go', 'sql'], // 只留几种；不写 = 全部
    defaultLanguage: 'python',
    highlight: true,        // false 只保留纯文本，语言标记照写
  },
})

editor.insertCode('const a = 1', 'js')
editor.setCodeLanguage('sql')   // 改写光标所在块
editor.getCodeLanguage()        // 不在块内返回 ''
editor.codeLanguages()          // [{ value, label, hint }, …]
editor.getState().inCode        // 光标是否在代码块内

// 纯函数：源码进、带 token 的 HTML 片段出（已转义）
KEditor.highlightCode(code, 'python')
KEditor.normalizeLang('MySQL')  // => 'sql'

工具栏

点开都是面板，不是一次性按钮

工具栏始终单行显示，放不下时可左右滑动，并有常显滚动条、边缘渐隐与首次引导气泡保证可发现性；「导入MD / 源码 / 全屏」固定吸附右端。

下拉面板 打开时自动记录并还原正文选区
